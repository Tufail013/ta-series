# TA SERIES — BS Nursing Results

Free results finder for BS Nursing students.

**Live site:** https://tufail013.github.io/ta-series/

## What this is

- One simple page. Tap the book to enter, pick your **Region, Semester, Batch
  and exam type**, then tap **Open Folder** to see your result.
- **Regular Results:** Normal, Fall, Spring.
- **Special Results — Separate Section:** Summer, Winter, Makeup only.
- **Links only.** No result file is uploaded here. Every file stays on
  Google Drive, and each result links to its parent Drive folder.
- Free for students. No ads.

## Files

- `index.html` — the whole site (design + finder, no build step).
- `data.js` — the 144 real result files, with their Drive folder links.

## How to add a new result

1. Upload the result PDF into its folder on Google Drive.
2. If the folder is already linked here, students see the new file at once —
   nothing else to do.
3. If it is a brand-new category (new region, batch or semester), add one
   line to `data.js` with the file name and its folder link, and the site
   updates itself.
